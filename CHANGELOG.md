# Changelog

## Release 2.0.0

* Update pdk to 3.4.0
* Installs 6.5.2 by default
* Installer now verifies download tgz with checksum
* More parameters to control
* Configures startup script, including selinux support
* Drop RedHat < 8 support
* Update module dependencies
* Add Puppet 7/8 support

## Release 1.0.0

* Added support for Ubuntu 18.04
* Replaced deprecated stankevich-python dependency a with puppet-python
* Updated pdk version
